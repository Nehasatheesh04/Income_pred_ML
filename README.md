💰 Income Prediction using Machine Learning

Built a machine learning model to predict whether an individual earns >50K or ≤50K based on demographic features.

🚀 Highlights

Performed data preprocessing & feature engineering

Applied one-hot encoding for categorical variables

Used Random Forest Classifier for prediction

Achieved ~85% accuracy with GridSearchCV tuning

⚙️ Tech Stack

Python • Pandas • NumPy • Scikit-learn
